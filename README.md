# BookStore (ООО «Книжный магазин») — Version 1.0.1

## О приложении

Данный проект представляет собой десктопное приложение для управления книжным магазином. Приложение позволяет вести каталог книг, управлять заказами, отслеживать продажи и работать с поставщиками. Система ориентирована на внутреннее использование сотрудниками магазина.

## Доступный функционал

На данный момент разработки (Версия 1.0.1) реализованы следующие возможности:

- Авторизация сотрудников магазина
- Просмотр и управление каталогом книг
- Оформление заказов и отслеживание продаж
- Работа с поставщиками и складским учётом
- Поиск книг по различным параметрам

## Технологический стек

- **C# / WPF** — десктопное приложение для Windows
- **Microsoft SQL Server** — база данных
- **Visual Studio** — среда разработки

## Инструкция по запуску

### 1. Подготовка базы данных

1. Установите Microsoft SQL Server, если он ещё не установлен
2. Создайте и наполните БД с помощью скрипта инициализации

### 2. Настройка проекта

1. Клонируйте репозиторий
2. Откройте `App.config` и укажите название вашего сервера SQL Server в строке подключения
3. Откройте `OOO_Bookstore.sln` в Visual Studio

### 3. Запуск

- **Стандартный режим:** запустите `bin\Debug\OOO_Bookstore.exe`
- **Режим отладки:** откройте решение `OOO_Bookstore.sln` в Visual Studio и нажмите F5
